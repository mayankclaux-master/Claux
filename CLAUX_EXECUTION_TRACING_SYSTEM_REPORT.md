### Trace Structure Standardization

**Event Structure**

All events follow canonical structure:
```typescript
{
  id: UUID,
  tenant_id: UUID,
  execution_id: UUID | null,
  event_name: string,
  event_source: string,
  payload: JSONPayload,
  event_version: string,
  correlation_id: string | null,
  causation_id: string | null,
  created_at: ISODateTime
}
```

**Correlation Tracking**

- correlation_id: Links related events in a distributed system
- causation_id: Links events in a causal chain
- Auto-generated by EventService if not provided

**Trace Query Pattern**

End-to-end trace reconstruction:
```typescript
// Get all events for an execution
const executionEvents = await eventRepository.fetchByExecutionId(executionId);

// Get all events for a task
const taskEvents = await eventRepository.fetchByTaskId(taskId);

// Get all events by correlation_id
const correlatedEvents = await eventRepository.fetchByCorrelationId(correlationId);

// Get all events by causation_id
const causalChain = await eventRepository.fetchByCausationId(causationId);
```

### Dashboard API Queryability

**EventRepository Methods**

**File**: `apps/web/lib/runtime/repositories/event.repository.ts`

Available query methods:
- `fetchByExecutionId(executionId)` - Get all events for an execution
- `fetchByTaskId(taskId)` - Get all events for a task
- `fetchByTenantId(tenantId)` - Get all events for a tenant
- `fetchByEventName(eventName)` - Get all events of a specific type
- `fetchByDateRange(startDate, endDate)` - Get events within date range
- `fetchByCorrelationId(correlationId)` - Get correlated events
- `fetchByCausationId(causationId)` - Get causal chain

**Dashboard API Endpoints**

Event queries are available via:
- `GET /api/events?execution_id={executionId}` - Query by execution
- `GET /api/events?task_id={taskId}` - Query by task
- `GET /api/events?correlation_id={correlationId}` - Query by correlation
- `GET /api/events?event_name={eventName}` - Query by event type
- `GET /api/events?tenant_id={tenantId}` - Query by tenant
- `GET /api/events?start_date={start}&end_date={end}` - Query by date range
